
# ⏱️ PyQt5 Stopwatch

A digital stopwatch application built with
Python and PyQt5.

## Features

- Start, Stop and Reset functionality
- Digital time display
- Hours, minutes, seconds and centiseconds
- Black background with red digits
- Arial font
- Accurate elapsed time tracking

## Technologies Used

- Python
- PyQt5
- QTimer
- QElapsedTimer

## Requirements

- Python 3
- PyQt5

## Installation

Install PyQt5:

```bash
pip install PyQt5
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/lazakour/pyqt5-stopwatch.git
```

Open the project folder:

```bash
cd pyqt5-stopwatch
```

Run the application:

```bash
python stopwatch.py
```
